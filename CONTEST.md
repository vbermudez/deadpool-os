## The Challenge

Create an AI agent that mimics a famous movie or TV character in a chatbot-like experience.
Your agent should behave, talk, and think like the character — not just repeat quotes.
You can build it as:

- 🌐 a web app
- 🖥️ a console app
- 🧪 a CLI tool
- 🐚 a fake shell that executes commands “as the character”
- 🤯 or something we haven’t thought of yet (preferred)

Examples (not exhaustive):

- A Yoda CLI that answers everything with inverted grammar
- A HAL 9000 shell that politely refuses to run your commands
- A Gandalf chatbot that blocks actions until you are “ready”
- A Terminator agent that only understands imperative verbs
- A Deadpool assistant that breaks the fourth wall and insults your code

## Rules (Soft, but important)

1. Core requirement
    - There must be an AI agent involved.
    - It must respond dynamically, not just via hardcoded scripts.
2. Character fidelity
    - We’re judging behavior, not quote databases.
    - The best entries will feel like you’re talking to the character.
3. Technology
    - Any stack is allowed.
    - Any AI approach is allowed (LLMs, agents, tools, prompt engineering, local models, etc.).
    - Bonus points if:
        - It works offline
        - It uses tools / function calling
        - It executes “commands” in character
4. Scope
   - This is not a production system.
    - Hacks, shortcuts, and duct tape are welcome.
    - Overengineering is encouraged only if it’s funny.

## 🏆 Judging Criteria

The winner will be chosen based on:

1. 🎭 Character Accuracy
    “I can hear the character in my head.”
2. 🤖 AI Cleverness
    Smart prompts, tools, agent behavior, or creative misuse of AI.
3. 🤣 Fun Factor
    Did it make people laugh, smile, or feel slightly uncomfortable?
4. ✨ Originality
    Unexpected ideas > polished UIs.

We are not judging:

- Code cleanliness
- Performance
- Security
- Anyone’s dignity
